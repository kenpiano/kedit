# KEdit

A simple, lightweight text editor built with HTML, CSS, and JavaScript.

## Features

- Create new files
- Open existing text files
- Save files to your computer
- Basic text editing with undo/redo functionality
- Copy and paste operations
- Keyboard shortcuts for common operations
- Real-time cursor position tracking
- Responsive design that works on different screen sizes

## Usage

1. Open `index.html` in your web browser
2. Start typing in the text area
3. Use the toolbar buttons or keyboard shortcuts:
   - **New**: Create a new file (Ctrl+N)
   - **Open**: Open an existing file (Ctrl+O)
   - **Save**: Save current content (Ctrl+S)
   - **Undo**: Undo last change (Ctrl+Z)
   - **Redo**: Redo last undone change (Ctrl+Y or Ctrl+Shift+Z)
   - **Copy**: Copy selected text (Ctrl+C)
   - **Paste**: Paste from clipboard (Ctrl+V)

## File Support

KEdit supports common text file formats including:
- Plain text (.txt)
- Markdown (.md)
- JavaScript (.js)
- HTML (.html)
- CSS (.css)
- JSON (.json)

## Browser Compatibility

Works with modern web browsers that support:
- ES6 JavaScript features
- Clipboard API
- File API
